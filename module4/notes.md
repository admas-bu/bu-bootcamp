# Module 4 Notes

In module 4, we learned about version control, Git, and how to use GitHub.

- Version control helps track changes to files over time.
- Git is a distributed version control system used to manage project history.
- GitHub is a platform for hosting Git repositories and collaborating with others.
- Common Git commands include:
  - `git init` to initialize a repository
  - `git add` to stage changes
  - `git commit` to save changes
  - `git push` to upload commits to GitHub
  - `git pull` to update from a remote repository

We also practiced using branches, commits, and remote repositories to collaborate efficiently.
